# מי המתחזה? 🚀

משחק חשיפה חברתי מקורי בעברית, שמשחקים בדפדפן עם חברים או מול בוטים. מתאים למחשב ולטלפון.

**לשחק:** https://liav-melamud.github.io/mi-hamitchaze/

- **🎮 דמו:** הדרכה צעד אחר צעד מול בוטים.
- **✨ צור חדר:** כל אחד יכול לארח. שולחים לחברים את הקישור או את הקוד בן 4 התווים. הלשונית של המארח צריכה להישאר פתוחה.

**תפקידים:** איש צוות · מהנדס · מדען · מלאך שומר · מתחזה · משנה צורה, ועוד תפקידים מיוחדים (סייר, ליצן, קורבן, נשר ועוד). הקוד `54321` בהגדרות מפעיל 20 תפקידי מוד נוספים.

**מצבי משחק:** קלאסי · מירוץ · מחבואים (הקוד `12345` מפעיל מקומות מסתור) · הפתעה.

**בתחנה:** שלוש מפות, משימות עם מיני-משחקים, סריקה ביולוגית, רשתות פתחי אוורור, חבלות, צ'אט קולי לפי קרבה, בוטים שמדברים ומצביעים (בעברית ובאנגלית), חנות כובעים וחיות מחמד.

**לובי חללית:** לפני המשחק כולם מסתובבים בחללית קטנה. בארון משנים צבע, כובע וחיה; במחשב המארח משנה הגדרות; בלוח התפקידים רואים מה כל תפקיד עושה וכמה סיכוי שיופיע. קוד החדר מוצג בצד.

**אירוע חנוכה (22.11–12.12.2026):** חנוכייה בלובי (לפני 4.12 דולק רק הנר התשיעי, ומ-4.12 נדלק עוד נר בכל יום; משחק ביום מדליק את הנר שלך ונותן תג), מצב "שמונה נרות" (הצוות מדליק, המתחזים מכבים), התפקיד "השמש" (נס פח השמן), משימת סביבון, כובע חנוכייה, כובע מכבי זהב, חיות סופגנייה וסביבון, ואווירת חג על המפה והלובי. אחרי התאריכים הכל זמין עם הקוד `8888` בהגדרות. הליצן והמודים נשארים בקוד `54321`.

**שפות:** עברית ואנגלית (החלפה בהגדרות, הדף נטען מחדש).

**אפליקציה לאנדרואיד:** https://liav-melamud.github.io/mi-hamitchaze/app.html מוריד את ה-APK אוטומטית. האפליקציה כוללת עותק מקומי, ולכן נפתחת גם בלי אינטרנט (מצב מקומי/משחק מול בוטים). בניית ה-APK רצה אוטומטית ב-GitHub Actions (`android/`).

**בדיקות:** `node tests/run.js`

## 🏠 מקומי / 🌐 אונליין

במסך הפתיחה בוחרים:
- **🏠 מקומי** – כולם באותו Wi-Fi. נכנסים לאתר, יוצרים חדר ושולחים קוד. בלי שום הגדרה.
- **🌐 אונליין** – חברים מרחוק (מדינה אחרת). עובר דרך שרת ההכוונה הפרטי (ראו `peer-server/`).

הקישור שהמארח שולח כבר כולל את המצב, ואם מישהו בחר מצב לא נכון, המשחק מנסה אוטומטית גם את השני.

### (רשות) שרת בית בלי אינטרנט בכלל
אם אין אינטרנט בבית: `npm install` ואז `npm start` במחשב אחד, וכולם נכנסים לכתובת שהוא מציג. במצב הזה אין צ'אט קולי.
