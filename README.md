# מי המתחזה? 🚀

משחק חשיפה חברתי מקורי בעברית, שמשחקים בדפדפן עם חברים או מול בוטים. מתאים למחשב ולטלפון.

**לשחק:** https://liav-melamud.github.io/mi-hamitchaze/

- **🎮 דמו:** הדרכה צעד אחר צעד מול בוטים.
- **✨ צור חדר:** כל אחד יכול לארח. שולחים לחברים את הקישור או את הקוד בן 4 התווים. הלשונית של המארח צריכה להישאר פתוחה.

**תפקידים:** איש צוות · מהנדס · מדען · מלאך שומר · מתחזה · משנה צורה

**בתחנה:** 14 חדרים, משימות עם מיני-משחקים (כבלים, קוד, מחוג), סריקה ביולוגית שכולם רואים, 4 רשתות של פתחי אוורור, חנות כובעים והגדרות לובי.
