# מי המתחזה? 🚀

משחק חשיפה חברתי מקורי בעברית, שמשחקים בדפדפן עם חברים. מתאים למחשב ולטלפון.

**איך משחקים:** אחד השחקנים לוחץ "צור חדר חדש" ושולח לחברים את הקישור או את קוד החדר. מי שיצר את החדר מריץ את המשחק בדפדפן שלו, אז הלשונית שלו צריכה להישאר פתוחה.

תפקידים: איש צוות · מהנדס · מדען · מלאך שומר · מתחזה · משנה צורה.
המארח יכול להפעיל **מצב חשיפת תפקידים** (H). במצב הזה כולם רואים קווי מעקב ותגיות תפקיד מעל כל שחקן.
