# שרת הכוונה למשחק

1. ב-https://render.com צור חשבון (חינמי).
2. לחץ "New" ← "Web Service" ← חבר את מאגר GitHub `liav-melamud/mi-hamitchaze`.
3. הגדרות: Root Directory = `peer-server`, Build Command = `npm install`, Start Command = `npm start`, Plan = Free.
4. אחרי ההפעלה תקבל כתובת כמו `https://mi-hamitchaze-peer.onrender.com`. שלח אותה לי.
